# ปรียาฟาร์ม OS

ระบบจัดการฟาร์มไข่: แดชบอร์ดฟาร์ม + พนักงานรับเอกสารผ่าน LINE OA ที่อ่านใบงานด้วย AI

- `/` เข้าสู่ระบบ (ครั้งแรกจะให้สร้างบัญชีเจ้าของฟาร์ม)
- `/farm/` แดชบอร์ดฟาร์ม แต่ละบัญชีเห็นตามบทบาท (ทีมฟาร์ม / คนงานไม่เห็นเงิน / ล้ง / ลูกค้า)
- `/app` หลังบ้าน: กล่องเอกสาร, ส่งรูปเอง, บัญชีผู้ใช้, LINE OA, ตั้งค่า AI, API keys, ทดสอบ OCR เทียบเจ้า, ข้อมูลในระบบ

## ขึ้น Vercel (ทำครั้งเดียว)

1. Vercel → Add New → Project → เลือก repo นี้ → Framework Preset: **Other** → Deploy
2. ในโปรเจกต์ → **Storage** → Create Database → **Neon** (ฟรี) → Connect กับโปรเจกต์นี้ Vercel จะใส่ `DATABASE_URL` ให้เอง
3. **Settings → Environment Variables** เพิ่ม
   - `APP_SECRET` = ข้อความลับยาวๆ อย่างน้อย 32 ตัว (ใช้เข้ารหัส API key และรหัส LINE ห้ามเปลี่ยนหลังใช้งานจริง ไม่งั้นต้องใส่ key ใหม่ทั้งหมด)
   - `CRON_SECRET` = ข้อความลับอีกชุด (กันคนนอกสั่งส่งสรุปรายวัน)
4. Deployments → Redeploy แล้วเปิดเว็บ สร้างบัญชีเจ้าของฟาร์ม
5. หน้า **API keys** ใส่ key → หน้า **ตั้งค่า AI** เลือกค่าย/โมเดล/key ของแต่ละงาน
6. หน้า **LINE OA** ทำตาม 6 ขั้นบนหน้าจอ (คัดลอก Webhook URL ไปวางใน LINE Developers)

ตารางในฐานข้อมูลสร้างเองตอนเรียกครั้งแรก ไม่ต้องรันอะไรเพิ่ม

## เอกสารที่อ่านได้ตอนนี้

| ประเภท | บันทึกไปที่ | ตรวจอะไร |
|---|---|---|
| ใบบันทึกประจำวันของเล้า | records | อาหารเข้า+เหลือ=รวม, รวม−ใช้=เหลือ, มิเตอร์น้ำ, ไข่เช้า+เย็น=รวม, ขนาดรวม=ไข่รวม, ต่อยอดจากวันก่อน, ห่างจากวันก่อนไม่เกิน ±25% |
| ตารางสรุปหลายเล้า | records | วันที่ / ค่าแต่ละแถว |
| ใบชั่งรถขายไก่ปลด | hensales (ราคารอใส่) | ชั่งออก−ชั่งเข้า=สุทธิ, 1.5–2.6 กก./ตัว, ต้องรู้เล้าและจำนวนตัว |
| ใบหน้าฟาร์ม (ทะเบียน/จำนวนไก่) | gatelog | ผลรวมแต่ละคัน=ยอดรวม, เทียบกับใบชั่งวันเดียวกันตามทะเบียน |
| ใบอุณหภูมิตู้เย็นวัคซีน | fridge | 2–8°C |
| ใบส่งอาหาร | feeddel | ลงไซโลรวม≈น้ำหนักชั่ง |

ความมั่นใจ = ค่าต่ำสุดของทุกช่อง โดยรวม คะแนนที่ AI ให้ตัวเอง + อ่านซ้ำรอบ 2 (ถ้าเปิด) + ตรวจตัวเลข + คนยืนยัน
ถึงเกณฑ์ (ตั้งได้ ค่าเริ่ม 90%) และไม่มีตัวเลขที่ขัดกัน → บันทึกเอง; ไม่ถึง → ถามในกลุ่มทีละช่อง (สูงสุด 3) → ไม่มีคนตอบภายใน 3 ชม. → เข้ากล่องเอกสารให้ผู้บริหาร
